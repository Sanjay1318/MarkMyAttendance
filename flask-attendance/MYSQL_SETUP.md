# MySQL Connection Guide

## How the database connection works

The app reads your MySQL credentials from a `.env` file.
If `DB_PASSWORD` is missing or empty it falls back to SQLite automatically.

```
Your .env file
    ↓
app.py reads with python-dotenv
    ↓
SQLAlchemy builds the connection URI:
  mysql+pymysql://USER:PASSWORD@HOST:PORT/DB_NAME?charset=utf8mb4
    ↓
PyMySQL driver connects to MySQL
```

---

## Step-by-step: Connect to MySQL

### Step 1 — Install MySQL (if not already)

- **Windows**: Download MySQL Installer from https://dev.mysql.com/downloads/installer/
- **macOS**: `brew install mysql`
- **Ubuntu/Debian**: `sudo apt install mysql-server`

### Step 2 — Create the database

Open MySQL shell:
```bash
mysql -u root -p
```

Run:
```sql
CREATE DATABASE attendance_db
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

-- Optionally create a dedicated user (recommended over root):
CREATE USER 'attendms'@'localhost' IDENTIFIED BY 'your_strong_password';
GRANT ALL PRIVILEGES ON attendance_db.* TO 'attendms'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### Step 3 — Load the SQL dump

```bash
mysql -u root -p attendance_db < attendance_db.sql
```

Or with the dedicated user:
```bash
mysql -u attendms -p attendance_db < attendance_db.sql
```

This imports:
- 8 classes (Grade 1–8)
- 16 arms (A & B per grade)
- 16 teachers
- 224 students
- 6 session/terms (2022/23 T1,T2,T3 → 2023/24 T1,T2 → 2024/25 T1 active)
- ~77,000 attendance records

### Step 4 — Create the .env file

Copy the example file:
```bash
cp .env.example .env
```

Edit `.env`:
```env
SECRET_KEY=replace-this-with-a-50-char-random-string

DB_HOST=localhost
DB_PORT=3306
DB_USER=attendms
DB_PASSWORD=your_strong_password
DB_NAME=attendance_db

FLASK_DEBUG=1
```

### Step 5 — Run the app

```bash
python app.py
```

The app will connect to MySQL. You'll see in the terminal:
```
 * Running on http://127.0.0.1:5000
```

## Alternative: Keep using SQLite

If you don't want to set up MySQL at all, simply leave `DB_PASSWORD` empty (or don't create a `.env` file).
The app will use `instance/attendance.db` automatically — the same file generated by `seed_real.py`.

To use the pre-seeded SQLite database just run:
```bash
python seed_real.py    # creates instance/attendance.db with all 224 students
python app.py          # uses SQLite automatically
```

## Re-seeding the database

To wipe and re-generate all data:

**SQLite:**
```bash
python seed_real.py
```

**MySQL:**
```bash
python seed_real.py --mysql
```

## Environment variables reference

| Variable | Example | Description |
|---|---|---|
| `SECRET_KEY` | `abc123...` | Flask session secret — change in production! |
| `DB_HOST` | `localhost` | MySQL host |
| `DB_PORT` | `3306` | MySQL port |
| `DB_USER` | `attendms` | MySQL username |
| `DB_PASSWORD` | `yourpassword` | MySQL password — **leave blank for SQLite** |
| `DB_NAME` | `attendance_db` | MySQL database name |
| `FLASK_DEBUG` | `1` | `1` = debug mode on, `0` = production |

## Troubleshooting

**"Access denied for user"**
→ Wrong username/password in `.env`. Double-check `DB_USER` and `DB_PASSWORD`.

**"Unknown database 'attendance_db'"**
→ You haven't created the database yet. Run the `CREATE DATABASE` SQL above.

**"Can't connect to MySQL server"**
→ MySQL is not running. Start it:
- Windows: Open Services → MySQL → Start
- macOS: `brew services start mysql`
- Linux: `sudo systemctl start mysql`

**App still uses SQLite even after setting .env**
→ Make sure `DB_PASSWORD` is not empty and `python-dotenv` is installed:
```bash
pip install python-dotenv
```

**Import error on large SQL dump**
→ Increase MySQL max_allowed_packet:
```sql
SET GLOBAL max_allowed_packet=64*1024*1024;
```
Or add to `my.cnf`: `max_allowed_packet=64M`
